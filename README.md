# T-MINUS · 距离 2026.11.01 12:00

以《明日方舟》SideStory「时间啊，向前！」先导 PV 作为动态背景的倒计时页面。
深色电影感调色 + 冰蓝色点缀，画面中央只有一行「距离活动开始还有」和「天 : 时 : 分」倒计时。

## 打开方式

直接双击 `index.html`（推荐 Chrome / Edge）。
若浏览器对本地文件限制较严，可在本目录启动一个静态服务器：

```powershell
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 交互说明

- **进入层**：页面打开时先看到一个独立的进入页 —— 纯色深底 + 居中的「点击进入」文字，不显示视频和倒计时；点击页面任意位置进入。
- **音画同步**：点击进入的同一个手势内，背景视频与背景音乐都回到 0 秒并同时开始播放，随后进入层淡出、主界面淡入。视频静音、循环播放。
- **声音渐入**：音乐音量从 0 在约 3 秒内平滑渐入到 `0.45`（相对系统音量的偏轻背景音量，不会突然变响），没有静音按钮。
- **滚轮 / 拖拽**：进入后滚动鼠标滚轮，倒计时会被「拉走」并轻微旋转、缩放，松手后以弹簧缓动回位；手机上可直接用手指拖动倒计时，效果一致。
- **到点之后**：2026.11.01 12:00 一到，数字停在 `00:00:00`，文案变为「活动已开始」，数字转为冰蓝色并有一次轻微闪光，视频与音乐继续播放。
- **光标视差**：移动鼠标时，背景与倒计时会有极轻微的位移，并有一团柔和光晕跟随。

## 自定义

| 内容 | 位置 |
| --- | --- |
| 目标时间 | `app.js` 顶部 `TARGET`（默认 `2026-11-01T12:00:00+08:00`） |
| 渐入音量 / 时长 | `app.js` 中 `TARGET_VOLUME`、`FADE_DURATION`、`FADE_DELAY` |
| 主色 / 字体 / 间距 | `styles.css` 顶部 `:root` 变量 |
| 视频、音频 | `assets/bg-video.mp4`、`assets/bgm.mp3` |

> 目标时间带 `+08:00` 时区偏移，因此无论访问者处于哪个时区，倒计时都对准北京时间 2026.11.01 12:00。

## 文件结构

```
index.html          页面结构（含独立进入层）
styles.css          视觉与响应式样式
app.js              倒计时、进入层与音画同步、视差
assets/bg-video.mp4 背景视频（进入后循环、静音）
assets/bgm.mp3      背景音乐
preview.png         主界面效果预览
```
